# Email Extractor

## A simple Python-based Email Extractor that automatically identifies and extracts email addresses from a text file and saves them into an output file.

## Features

- Extract Email Addresses: Finds email addresses from the input text file.
- View Saved Emails: Displays all previously extracted email addresses.
- Count Email Addresses: Shows the total number of saved email addresses.
- Save Results: Stores extracted email addresses in "output.txt".
- Menu-Driven Program: Provides simple options to perform different operations.

## Technologies Used

- Python
- Regular Expressions ("re" module)
- File Handling

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

python main.py

5. Select an option from the menu.

## Menu Options

1. Extract Email Addresses
2. View Saved Email Addresses
3. Count Email Addresses
4. Exit

## Project Objective

The main objective of this project is to learn Python programming concepts such as regular expressions, file handling, functions, loops, and conditional statements through a practical application.
